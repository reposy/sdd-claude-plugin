# sdd-validate

읽기 전용 운영 skill. 검증은 서브에이전트에 위임.

## 동작

1. `sdd/` 디렉터리 존재 확인. 없으면 stop + `sdd-init` 권유.
2. **`agents/sdd-validate-agent.md` 서브에이전트 호출**. 인수 `{path}`(선택) 전달.
3. 서브에이전트가 모든 산출물에 가이드별 검증 체크리스트 적용 → 빈틈 보고.
4. 메인 대화에 결과만 표시.

## 약속

- 산출물 파일 변경 없음.
- 보고 형식: 산출물별 ✓/✗, ✗인 경우 어느 체크리스트 항목 위반인지 명시 (예: SPEC_GUIDE 검증 §3).
- 우선 수정 권장 표시 (다른 산출물의 근거가 되는 것 우선).
