# sdd-next

읽기 전용 운영 skill. 분석은 서브에이전트에 위임.

## 동작

1. `sdd/` 디렉터리 존재 확인. 없으면 stop + `sdd-init` 권유.
2. **`agents/sdd-next-agent.md` 서브에이전트 호출**.
3. 서브에이전트가 INDEX들 + 가이드 우선순위 기준으로 다음 행동 추천 (우선순위 + 이유 명시).
4. 메인 대화에 추천만 표시.

## 약속

- 산출물 파일 변경 없음.
- 보고 형식: 우선순위 순 권장 작업 목록 + 각 작업의 이유.
- `sdd-status`와 차이: status는 사실 나열, next는 우선순위 + 이유 추천.
