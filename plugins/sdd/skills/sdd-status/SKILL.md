# sdd-status

읽기 전용 운영 skill. 무거운 INDEX 처리는 서브에이전트에 위임.

## 동작

1. `sdd/` 디렉터리 존재 확인. 없으면 stop + `sdd-init` 권유.
2. **`agents/sdd-status-agent.md` 서브에이전트 호출**. 사용자 메시지를 그대로 전달.
3. 서브에이전트가 모든 INDEX를 읽고 요약 반환.
4. 메인 대화에 요약만 표시.

## 약속

- 산출물 파일 변경 없음 (읽기 전용).
- 보고 형식: 산출물 종류별 통계 (작성·진행·완료 수). 자세한 내용은 INDEX 직접 참조 권유.
